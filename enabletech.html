Web & accessibility

EnableTech Website

A WCAG 2.1 AA conformant site, built accessibility-first for a student club.

The approach

Build EnableTech’s web presence accessibility-first: semantic structure, a logical heading order, and landmark regions so assistive technology can move through the page predictably; full keyboard operability with visible focus; respected reduced-motion preferences; and ARIA only where native semantics fall short.

How it turned out

A site checked against WCAG 2.1 AA for colour contrast, alternative text, and focus management.
